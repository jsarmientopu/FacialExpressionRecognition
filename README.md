# Facial Expression Recognition

Machine learning project focused on **facial expression classification** using the **FER2013 dataset**. The project explores different machine learning and deep learning approaches and compares their performance.

## Models

* **SVM** with PCA-based feature reduction
* **VGG19-style Convolutional Neural Network**
* Additional CNN models for hypothesis testing

## Dataset

**FER2013** — 35,887 grayscale facial images classified into seven emotions:

* Anger
* Disgust
* Fear
* Happiness
* Sadness
* Surprise
* Neutral

## Technologies

* Python
* TensorFlow / Keras
* Scikit-learn
* NumPy
* Pandas
* Matplotlib

## Results

The VGG19-style CNN achieved approximately **63% accuracy** and a **63.18% F1-score** on the test set. The project also highlights the impact of dataset quality and preprocessing on facial expression recognition performance.
